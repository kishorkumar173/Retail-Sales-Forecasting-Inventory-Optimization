# 🛒 Retail Sales Forecasting & Inventory Optimization System

## 📌 Project Overview
This project predicts future retail sales using machine learning and optimizes inventory decisions such as safety stock, reorder point, and order quantity.

---

## 🎯 Problem Statement
Retail businesses often face:
- Overstocking (capital loss)
- Stockouts (lost sales)

This system helps maintain optimal inventory using demand forecasting.

---

## 💡 Solution
- Forecast sales using Random Forest
- Apply inventory optimization techniques:
  - Safety Stock
  - Reorder Point (ROP)
  - Order Quantity
